Arquitetura de Superfícies & Layouts 2026

O Design System da Organiza AI consolida toda a identidade visual da plataforma em torno de superfícies glassmorphic de anel único (Single-Ring Glassmorphism), tipografia geométrica humanista Plus Jakarta Sans, paleta canônica Rosa-Laranja-Amarelo, e componentes estruturais responsivos com ChangeDetectionStrategy.OnPush e Signals do Angular 21+.

Princípios Centrais
  • Composição limpa com [orgSurface], <org-page-layout> e <org-section>
  • Acessibilidade WCAG 2.1 AA com alvos de toque mínimos de 48px
  • Zero overflow horizontal em todos os viewports móveis e desktops
Proibições Arquiteturais
  • Nunca escrever classes de vidro legadas (.glass-card, .org-glass)
  • Nunca escrever backdrop-filter manual nas folhas SCSS de features
  • Nunca criar breakpoints fora do padrão 600px / 900px / 1200px

Breakpoints Padronizados (600px / 900px / 1200px)

A plataforma utiliza rigorosamente três limites de responsividade mobile-first, banindo breakpoints arbitrários.

Dispositivo / Viewport Breakpoint Media Query Comportamento Principal
Mobile < 600px 1 coluna fluida, alvos 48px, padding 16px 12px
Tablet / Small @media (min-width: 600px) 2 colunas em grids, drawer modal, padding 24px 16px
Desktop / Medium @media (min-width: 900px) Sidebar sticky visível, layouts amplos (960px)
Wide Screen @media (min-width: 1200px) Layouts wide (1200px) e formulários multi-colunas

[orgSurface]

src/app/shared/ui/surface/org-surface.directive.ts

Aplica vidro translúcido com anel único (gradiente Rosa para Laranja) e sombras reflexivas a qualquer elemento HTML.

Quando usar
  • Cards de eventos, resumos e listas
  • Painéis de cabeçalho e estatísticas
  • Gavetas (drawers) e modais (dialogs)
Quando NÃO usar
  • Elementos inline simples ou textos puros
  • Sobreposições múltiplas de vidro aninhadas

Variante Card

Padding responsivo 16px/24px e raio 16px.

Variante Panel

Padding 20px/32px e raio 20px para containers principais.

O que FAZER (DO)
  • Usar [orgSurface] para qualquer card, painel ou diálogo
  • Utilizar sempre as cores canônicas Rosa (#ff4d94), Laranja (#ff8c42) e Amarelo (#ffc837)
  • Garantir alvos de toque mínimos de 48px em botões e controles móveis
  • Estruturar páginas com <org-page-layout> e <org-section>
  • Utilizar [orgFormGrid] para disposição responsiva de inputs
O que NÃO FAZER (DON'T)
  • NUNCA escrever backdrop-filter manual nas folhas SCSS de features
  • NUNCA utilizar as classes legadas .glass-card ou .org-glass
  • NUNCA utilizar cores hexadecimais obsoletas (#630ed4, #6366f1, #38bdf8, #00bfa5)
  • NUNCA usar !important para sobrescrever estilos internos do Material
  • NUNCA criar breakpoints arbitrários fora de 600px / 900px / 1200px
